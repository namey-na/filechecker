
# File Checker

A lightweight tool for scanning files and folders for known cheat-related files, modifications, or suspicious patterns.

## Features

* Scans selected files and directories
* Checks for known cheat signatures and filenames
* Provides clear scan results
* Designed to be simple and easy to use


The checker will scan the specified path and report any potentially suspicious files it finds.

## Disclaimer

This project is intended for educational and security purposes. Detection results may produce false positives and should be manually reviewed.
